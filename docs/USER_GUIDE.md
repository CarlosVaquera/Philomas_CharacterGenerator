# User Guide

This guide explains how to add characters, what you edit manually, what the
pipeline generates for you, and which VS Code task to run.

## Character Ids

Every character has a `character_id`. It is the lowercase id used in filenames
and folders.

Examples:

```text
pepe
lola
dr_miedo
guitar-ghost
```

Use only lowercase letters, numbers, hyphens, and underscores.

## Add a New Character

Use VS Code:

1. Open `Terminal > Run Task...`.
2. Run `Philomas: 04 Create Character`.
3. Enter the new `character_id`, for example `lola`.
4. Enter the display name, for example `Lola`.

This creates:

```text
data/characters/<character_id>.yaml
prompts/generated/<character_id>/.gitkeep
assets/raw/<character_id>/.gitkeep
assets/clean/<character_id>/.gitkeep
assets/export/<character_id>/.gitkeep
```

Then edit the new file under `data/characters/`.

You can also use the CLI:

```bash
philomas-pipeline create-character lola --name "Lola"
```

## What You Edit Manually

The main manual input is the character data file:

```text
data/characters/<character_id>.yaml
```

Edit this file when you want to change:

- `name`
- `role`
- `theme`
- `personality`
- `physical_appearance`
- `clothing`
- `equipment`
- `supernatural_theme`
- `palette`
- `frame_size`
- `sheet_layout`
- `hitbox`

The global project style input is:

```text
data/project_style.yaml
```

Edit this file when you want to change the shared visual direction:

- base resolution
- pixel art style
- mood
- visual restrictions
- output rules

The animation input is:

```text
data/animations.yaml
```

Edit this file when you want to change animation names or frame counts.

The optional prompt wording input is:

```text
prompts/templates/
```

Edit these templates only if you want to change how the generated prompts are
written.

## What You Do Not Edit Manually

These files are generated by the pipeline:

```text
prompts/generated/<character_id>/*.txt
assets/raw/<character_id>/<character_id>_placeholder_spritesheet.png
assets/export/<character_id>/metadata.json
```

Do not treat those files as source input. If you need different outputs, edit
the files under `data/` or `prompts/templates/`, then run the pipeline again.

The folder below is reserved for a future cleanup stage:

```text
assets/clean/<character_id>/
```

Right now it is not part of the active workflow.

## First Time Setup

Open the `philomas-character-pipeline` folder in VS Code.

Then:

1. Select a Python 3.11+ interpreter.
2. Open `Terminal > Run Task...`.
3. Run `Philomas: 00 First Time Setup + Run`.
4. Run `Philomas: 03 Run Tests`.

Task `00` installs dependencies and then asks which character to run. The
default is `pepe`.

## Normal Workflow

After the first setup, the normal workflow is:

1. Edit `data/characters/<character_id>.yaml`.
2. Edit `data/project_style.yaml` or `data/animations.yaml` only if needed.
3. Run `Philomas: 02 Run Pipeline`.
4. Enter the `character_id` when VS Code asks.
5. Run `Philomas: 03 Run Tests`.
6. Inspect the generated files if needed.

## Manual Step-by-step Workflow

Use these tasks only when you want to inspect or debug each stage:

1. `Philomas: Step A - Build Prompts`
2. `Philomas: Step B - Generate Placeholder`
3. `Philomas: Step C - Validate`
4. `Philomas: Step D - Export Metadata`

Each task asks for the `character_id`. The task `Philomas: 02 Run Pipeline`
runs all four stages for you.
